## 1. HIGH CONCEPT

Классический «Морской бой»: порт консольной игры на UE5 с игрой **по сети для двух игроков**.
Поле 10×10, флот из 10 кораблей, поочерёдные выстрелы. Игровая логика — на чистом C++
(без зависимостей от UE), движок — только презентация и сеть. Это делает логику тестируемой
через gtest и демонстрирует чистую архитектуру — «японский козырь №2».

**Питч:** «Тот самый морской бой из тетрадки, но с пиратским кораблём, водой и другом по сети».

## 3. ПРАВИЛА (спецификация логики)

### 3.1 Поле и флот
- Поле 10×10, координаты A1…J10 (строки A–J, столбцы 1–10).
- Флот: 1 корабль × 4 палубы, 2 × 3, 3 × 2, 4 × 1 (всего 10 кораблей, 20 клеток).
- Корабли не касаются друг друга (включая углы) — минимум 1 клетка между.
- Корабли можно располагать горизонтально и вертикально.

### 3.2 Ход игры
- Игроки стреляют по очереди. Ход передаётся только после **промаха**.
- Попадание → повторный ход. Отметка «ранен» / «убит» (когда все палубы корабля поражены).
- Победа: уничтожен весь флот противника.

### 3.3 Дополнительно (v0.1)
- Авто-расстановка + ручная расстановка.
- Случайный выбор первого хода.
- Честная сеть: решения принимает сервер (авторитетная логика), клиент шлёт намерение.

```
Главное меню
   └─ Создать игру (Listen Server) / Подключиться по IP
        └─ Лобби (готовность 2 игроков)
             └─ Расстановка кораблей (оба игрока, затем «Готов»)
                  └─ Боевая фаза: поочерёдные выстрелы по сетке
                       └─ Попадание/промах/потопление → смена хода
                            └─ Экран победы/поражения → «Сыграть ещё»
```

## 5. ТЕХНИЧЕСКАЯ АРХИТЕКТУРА

```
┌────────────────────────────────────────────────────┐
│ UI (UMG): меню, лобби, поле, результат             │  ← Blueprint 20%
├────────────────────────────────────────────────────┤
│ UE-слой (презентация): GameMode, PlayerController, │
│ BoardActor (сетка), ShipActor (корабли)            │  ← C++ 80%
├────────────────────────────────────────────────────┤
│ Сеть: Listen Server, Replication, RPC              │
├────────────────────────────────────────────────────┤
│ CORE (чистый C++): поле, корабли, правила,         │
│ расстановка, попадания, победа — БЕЗ UE-зависимостей│  ← gtest
└────────────────────────────────────────────────────┘
```

### Модули (структура Source/)
```
Source/SeaBattle/
  Core/            — чистая логика (без UE)
    Battlefield.h   // поле 10×10, корабли, выстрелы
    Ship.h          // корабль: палубы, ориентация, состояние
    GameRules.h     // правила: смена хода, победа
    ShipPlacer.h    // авто-расстановка
  CoreTests/        — gtest (консольная цель, без UE)
  Game/             — UE-обвязка: GameMode, PlayerController, BoardActor, ShipActor
  UI/               — виджеты UMG (C++ + Blueprint)
```

### Ключевой принцип
`Core` не включает ни одного UE-заголовка. UE-слой вызывает Core, а не наоборот.
Это даёт: gtest без редактора, чистые интерфейсы, быстрый CI.

## 6. UI / UX

| Экран | Содержимое |
|---|---|
| Главное меню | Создать игру / Подключиться / Выход |
| Лобби | Имя игрока, IP для подключения, кнопка «Готов», старт у хоста |
| Расстановка | Своя сетка 10×10, перетаскивание/поворот корабля, авто-расстановка, «Готов» |
| Бой | Своя сетка (слева) + чужая сетка для выстрелов (справа), индикатор хода, отметки попаданий/промахов |
| Результат | Победа/поражение, статистика (точность, число выстрелов), «Сыграть ещё» |

Принципы: вся нужная информация на одном экране, никаких скрытых меню;
туман войны — поле противника видно только по своим выстрелам.

## 7. АРТ И ЗВУК (минимум, режется первым)

- Стиль: стилизованный low-poly/упрощённый, продолжение Модуля 3 (pirate_ship из Fab, клетка с M_CellMaterial).
- Вода: лёгкая анимация материала, волны.
- Эффекты попадания: всплеск (промах), взрыв/огонь (попадание), дым (потопление).
- Звук: минимальный набор (выстрел, взрыв, плеск) — синтез или бесплатные ассеты.
- **Звук и сложные VFX режутся в первую очередь при нехватке времени.**

## 8. СКОУП И «ЧТО РЕЖЕМ»

### Ядро (не трогаем)
- Поле 10×10, флот 10 кораблей, правила ходов, победа.
- Сеть: полная партия 2 игроков.
- Логика в Core + gtest.

### Режется первым (по убыванию)
1. Звук и VFX-полировка.
2. Статистика партии, «Сыграть ещё» в том же лобби.
3. Ручная расстановка (оставить только авто).
4. Красивое лобби (оставить минимальное).

### Stretch (если останется время)
- ИИ-противник (простой стрелок + «охотник» за подбитым кораблём).
- Чат в лобби. Смена скинов кораблей.
