# GitHub Project — как устроена доска (Roadmap 2026–2030)

> Этот файл описывает структуру доски, чтобы она была в git (жила вместе с проектом).

## Как создать доску (2 минуты, в браузере)

1. Открой репозиторий → вкладка **Projects** → **New project** → шаблон **Board**.
2. Название: **Roadmap 2026–2030**.
3. Колонки по умолчанию (Board): TODO / In Progress / Done.
4. В настройках доски → **Manage automation**: включи «When an issue is closed → move to Done».
5. Добавь созданные issues на доску: **+ Add cards** → выбрать issues (см. список ниже).

## Соглашения

- Каждый месяц = один issue-«контейнер» с чек-листом подзадач внутри.
- Метки (создать при желании): `core`, `content`, `polish`, `scope-cut-candidate`.
- Закрытый issue = переносится в Done автоматически (шаг 4).
- Полный план — в ROADMAP.md; доска — это оперативное зеркало на месяц вперёд.
